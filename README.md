# Wellbeing Branding Trip (Oct 2026)

Mobile-first trip checklist for Wellbeing Pharmacy branch visits.

**Live app (GitHub Pages):** https://cskeat.github.io/wellbeing-branding-trip/

**Live status Sheet:** https://docs.google.com/spreadsheets/d/1sM0GIPORgPaD2YQXQKGKeXGow6EfnHvQMVZY_2TmXyM/edit

## Sync
- **Pull from Sheet** loads status into the phone UI
- **Push to Sheet** writes done/skipped/notes back (via Apps Script bridge)

Share the Sheet as **Anyone with the link → Viewer** so CSV pull works; Push needs the Apps Script web app deployed (see `Code.gs` in repo).
